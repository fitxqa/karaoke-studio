# Karaoke Studio — Android app

Phone & tablet app (Android 6+), orange / black / white. It plays, records, scores and shares;
the heavy work (vocal removal, AI lyrics) runs in Karaoke Studio on your PC on the same Wi-Fi.

Build: push to GitHub → Actions → "Build Android APK" → download **KaraokeStudio-apk**.
Local build (needs Node 22, JDK 21, Android SDK): `npm install && npm run android:add && npm run apk`.
